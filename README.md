## 🚀 Getting Started

### 1. Prerequisites

```bash
flutter --version   # Requires Flutter ≥ 3.16
```

### 2. Clone & Install

```bash
git clone https://github.com/your-org/loyverse_pos.git
cd loyverse_pos
flutter pub get
```

### 3. Configure Firebase

```bash
# Install the FlutterFire CLI
dart pub global activate flutterfire_cli

# Log in and configure (generates lib/firebase_options.dart)
flutterfire configure --project=YOUR_FIREBASE_PROJECT_ID
```

The following Firebase services must be **enabled** in your Firebase console:
- ✅ Authentication → Email/Password
- ✅ Cloud Firestore (start in **test mode**, then apply the rules below)
- ✅ Firebase Storage

### 4. Firestore Security Rules

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users can read/write their own profile
    match /users/{userId} {
      allow read, write: if request.auth.uid == userId;
    }
    // Store data: only authenticated users of that store
    match /stores/{storeId}/{document=**} {
      allow read, write: if request.auth != null
        && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.storeId == storeId;
    }
  }
}
```

### 5. Run the App

```bash
# Android
flutter run -d <android-device-id>

# Windows
flutter run -d windows
```

## ☁️ Codemagic CI/CD

This project ships with a complete `codemagic.yaml`. To activate:

1. Push this repo to GitHub / GitLab / Bitbucket.
2. Log in to [codemagic.io](https://codemagic.io) and connect the repo.
3. Add the following **Environment Variables** in Codemagic UI:

| Variable | Description |
|---|---|
| `GOOGLE_SERVICES_JSON` | Base64-encoded `google-services.json` |
| `CM_KEYSTORE` | Base64-encoded `.jks` keystore |
| `CM_KEYSTORE_PASSWORD` | Keystore password |
| `CM_KEY_ALIAS` | Key alias |
| `CM_KEY_PASSWORD` | Key password |
| `SLACK_WEBHOOK_URL` | (Optional) Slack notifications |

### Encode a file to Base64

```bash
# macOS / Linux
base64 -i google-services.json | tr -d '\n'

# Windows PowerShell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("google-services.json"))
```

### Workflows available

| Workflow ID | Trigger | Output |
|---|---|---|
| `android-debug` | Push to `develop` | Debug APK |
| `android-release` | Git tag `v*` | Signed APK + AAB |
| `windows-release` | Git tag `v*` | Windows EXE zip |
| `multi-platform-release` | Tag `release/*` | AAB + coverage |

## 🗂 Project Structure

